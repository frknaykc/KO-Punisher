# Güvenlik bildirimi

Güvenlik açığı, hesap bilgisi veya gizli anahtar içeren raporları herkese açık issue olarak paylaşmayın.

Depoda etkinse GitHub **Security → Report a vulnerability** üzerinden özel bildirim gönderin. Bu seçenek görünmüyorsa, ayrıntıları veya exploit kodunu yayımlamadan depo sahibinden özel bir bildirim kanalı isteyin.

Rapora etkilenen commit, Windows/.NET sürümü, beklenen davranış, etki ve hassas veri içermeyen tekrar adımlarını ekleyin. Gerçek hesap bilgileri, özel anahtarlar veya kişisel ekran görüntüleri göndermeyin.

Proje geliştirme aşamasındadır; yanıt süresi veya eski sürümler için güvenlik desteği taahhüdü yoktur. Kullanıcı ayarları `%LOCALAPPDATA%\KO-Punisher` altında tutulur. Tanılama kayıtlarını paylaşmadan önce gözden geçirin.

Uygulama sentetik klavye/fare girişi gönderir. Hedef pencere kontrolü ve acil durdurma, sıfır gecikme veya yanlış pencereye hiçbir koşulda tuş gitmeyeceği garantisi değildir. Yönetici yetkisini gerekmedikçe vermeyin; güvenlik yazılımını kapatmayın.
