# Üçüncü taraf bileşenler ve içerikler

Bu belge proje koduna lisans vermez. Her bileşenin kendi lisansı ve hak sahipliği geçerlidir.

| Bileşen | Kullanım | Kaynak / lisans bilgisi |
|---|---|---|
| Tesseract 5.2.0 .NET wrapper | Native OCR API erişimi; NuGet üzerinden alınır | [charlesw/tesseract](https://github.com/charlesw/tesseract), Apache-2.0 |
| Tesseract OCR | Wrapper'ın kullandığı native OCR motoru | [tesseract-ocr/tesseract](https://github.com/tesseract-ocr/tesseract), Apache-2.0 |
| English traineddata | `KO-Punisher/tessdata/eng.traineddata` OCR modeli | [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast), Apache-2.0 |
| Skill ikonları | Skill kataloğu ve görsel eşleştirme | [Kaynak ve kapsam notları](docs/skill-catalog-sources.md); oyun görselleri ilgili hak sahiplerine aittir |

Depoda Apache License 2.0 metni [LICENSES/Apache-2.0.txt](LICENSES/Apache-2.0.txt) altında bulunur. Native dağıtımların içerdiği ilave bileşenlerin lisansları da dağıtım sırasında korunmalıdır.

Skill ikonlarının erişilebilir bir web sayfasından alınmış olması serbest lisanslı oldukları anlamına gelmez. Bu belge oyun görselleri için yeniden dağıtım izni iddia etmez. Hak sahipliği veya kaldırma talepleri için depo sahibiyle iletişime geçin.
